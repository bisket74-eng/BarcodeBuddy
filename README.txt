BARCODE BUDDY - LABEL PICTURE (NO PDF)
======================================

This update changes only the export.

- Share Label and Download Label now save a plain PNG picture instead
  of a PDF.
- The picture is exactly the label: 3.5 inches wide by 1 inch tall
  (1050 x 300 pixels, 300 dpi), barcode on top with the tracking
  number underneath. There is no page around it, so a label printer
  prints it edge to edge on the label.
- Desktop keyboard typing is unchanged.

Service-worker cache updated to barcode-buddy-v17.
