BARCODE BUDDY — 22, 24, OR 26 DIGITS
=====================================

This update changes only the accepted barcode-number lengths.

- Barcode Buddy now accepts exactly 22, 24, or 26 digits.
- It does not accept 23 or 25 digits.
- Manual entry stops at 26 positions.
- OCR accepts a single 22-, 24-, or 26-position numeric line.
- Code 128 scanning remains restricted so QR codes are ignored.
- All other behavior and styling remain unchanged.
- Service-worker cache updated to barcode-buddy-v10.

Replace every existing repository file with the files from this ZIP.
